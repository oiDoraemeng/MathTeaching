# enrich-linear-algebra-teaching-depth

把前三章 54 个线性代数主题升级为可审查、可持久化的“数形结合教学产物”：数学解释子智能体依据 `.agents/线性代数讲义.md` 生成结构化解释和视觉语义，软件保存已发布内容，并由确定性的视觉语义编译器生成与树节点绑定的教学图形。

本变更解决两类问题：

- 每章解释过于简略，缺少定义、推导、数字算例、几何意义、误解提醒和主题关联；
- 图形只显示少量向量，未表达零空间塌缩、矩阵复合顺序、投影垂足、行列式面积缩放和叉积方向等核心关系。

子智能体不直接执行绘图，也不生成代码或场景命令。它生成的数学对象、关系、阶段和不变量会被保存到 `TeachingArtifact`，再由软件编译为受校验的 `CommandPlan`。树形目录使用稳定 `topic_id` 同时关联讲义来源、解释、视觉语义和绘图配方。

实现前请先阅读 `proposal.md`、`design.md`、`specs/` 和 `tasks.md`；完成后依次运行来源校验、artifact/视觉契约校验和完整测试套件。
