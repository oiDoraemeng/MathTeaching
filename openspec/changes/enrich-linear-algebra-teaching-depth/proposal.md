# Proposal: 线性代数数形结合教学规划器

## Why

上一轮 `expand-linear-algebra-lecture-tree` 已建立前三章 54 个主题的树形目录、解释对象和主题 builder，但教学闭环仍然断裂：

1. 解释大多停留在摘要、公式和两条绘图操作，缺少从定义到推导、数值验证、几何意义和误解提醒的完整链路。
2. 图形常常只画几根向量，不能直接表达矩阵复合顺序、零空间塌缩、投影垂足、行列式面积缩放或叉积方向等核心论点。
3. 讲义来源、解释内容和绘图配方虽然通过 ID 松散连接，但没有一个可审查的中间产物同时描述“学生要理解什么”和“图上要呈现什么”。
4. 现有 `transformed_grid`、`subspace_region`、`staged_transform`、`oriented_area` 等能力已经存在，却缺少统一的语义编译层，导致声明能力与实际图形脱节。

## What Changes

- **引入数形结合教学子智能体**：子智能体读取《线性代数讲义.md》的主题片段和相邻上下文，输出结构化 `TeachingArtifact`。产物包含数学解释和由数学对象推导出的 `visual_semantics`，但不输出 Python、Qt、CommandPlan 或其他执行代码。
- **重写 54 个主题解释**：以讲义原文为唯一知识来源，补齐定义、公式、推导链、可复算数字例题、直觉、几何意义、常见误解和主题关联；核心主题还必须说明图中对象与公式变量的对应关系。
- **保存子智能体回复**：通过版本化、可审查的 JSON 内容包保存 `topic_id`、讲义锚点、源码哈希、模型版本、结构化解释和视觉语义。运行时只读取已发布产物，不因用户点击树节点而临时生成不稳定内容。
- **增加视觉语义编译器**：将受控的数学语义（向量、基、映射、投影、张成、阶段、面积、方向、比较等）编译成现有场景命令；编译器根据主题契约选择网格、子空间、投影、分阶段变换、有向面积和 3D 体几何原语。
- **强化树形绑定**：树叶的稳定 `topic_id` 同时索引讲义来源、教学产物和可视化 recipe。解释和图形经过共同校验后原子加载，任何一侧缺失或不匹配都不得加载另一侧的内容。
- **补足确实缺失的表达能力**：优先扩展 builder 原语和布局/标注语义；只有现有协议无法表达的数学关系才新增受约束的场景操作，例如阶段快照、终点比较、面积数值标注和 3D 旋转方向。
- **新增验证闭环**：校验来源锚点、解释数学字段、数字例题、视觉语义引用、主题契约和最终 plan 的实际 op，防止再次出现“声明了能力但图中没有”的退化。

## Capabilities

### New Capabilities

- `linear-algebra-explanation-agent`: 基于讲义片段生成“数学解释 + 视觉语义”的结构化教学产物。
- `linear-algebra-teaching-artifact`: 保存、加载、版本化和发布教学产物，并以 `topic_id` 关联讲义与图形。
- `linear-algebra-visual-semantics`: 将数学视觉语义编译为受校验的 `CommandPlan`，并执行主题级视觉契约。

### Modified Capabilities

- `linear-algebra-case-tabs`: 树节点不再只打开静态解释；它打开同一个 `TeachingArtifact` 的解释视图和对应图形。
- `linear-algebra-explanation-depth`: 深度解释字段和验证规则改为服务于 `TeachingArtifact`，不再把 `intuition/example` 当作完整教学内容的替代品。
- `linear-algebra-visual-primitives`: 高级图元由视觉语义编译器统一调用，builder 不得用普通向量冒充核心教学关系。
- `linear-algebra-color-contract`: 教学角色颜色同时服务视觉语义编译和解释图例。

## Impact

- **来源与内容层**：新增讲义片段读取、结构化产物模型、JSON schema、发布校验和子智能体适配器；重写前三章 54 个主题的解释资源。
- **可视化层**：新增视觉语义到原语的编译路径，增强重点主题的并排、分阶段、着色、投影、面积和 3D 关系表达；删除未使用的模板路径。
- **树形与加载层**：通过 `topic_id` 解析统一教学产物，校验通过后再提交场景和内容视图；失败时保留原场景并显示可诊断错误。
- **前端展示层**：Qt 和 Web 解释视图支持定义、推导、算例、误解、关联和读图提示；视觉语义本身不直接暴露为命令文本。
- **验证与测试**：增加讲义锚点/哈希、结构化数学内容、语义引用、主题视觉契约、能力到实际 op 的一致性和 54 主题覆盖测试。

## Non-Goals

- 不改动 `.agents/线性代数讲义.md`，不扩展前三章之外的课程树主题。
- 不让子智能体直接执行绘图或生成可执行代码，不在运行时把模型自由回复直接交给场景宿主。
- 不引入动画时间轴或连续参数调节；静态 plan 通过并排、分阶段和对比构图表达过程。
- 不把练习、自检、挑战题或纯符号推导伪装成几何主题。
