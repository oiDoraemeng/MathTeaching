# 线性代数案例标签

## Why

当前左侧代数面板只有函数目录，线性代数教学仍需要用户通过自然语言请求，无法快速打开可复现的图形案例和配套解释。右侧 Agent 已经有横向会话标签，但缺少与案例解释并列的内容类型。

## What Changes

- 在左侧“函数”按钮后增加“线性代数”入口。
- 提供向量加法、向量减法、向量数乘、向量内积、向量外积五个内置案例。
- 点击案例时清空当前场景，加载受白名单验证的二维教学图形。
- 将案例解释作为右侧横向标签栏中的独立案例标签展示，与 Agent 会话并列。
- 同一案例重复点击时复用已有标签并切换，不创建同名标签。
- 案例标签按标题自然宽度显示，并设置最小/最大宽度上限；标签过多时支持横向滚轮滚动并隐藏滚动条，同时保留关闭按钮。

## Non-goals

- 本变更不增加矩阵、行列式、特征值或线性变换案例。
- 本变更不改变 Agent 会话、运行时工具调用或 Qt/WebView 安全边界。
- 本变更不要求跨应用重启持久化案例标签。
