# Multi-Pane Workspace Design

**日期：** 2026-09-08  
**状态：** 头脑风暴后设计稿，待用户审核  
**关联 OpenSpec：** `openspec/changes/multi-pane-workspace/`

## 目标

为主工作区增加运行期多窗格能力。用户可以在右上角通过图标切换单、双、三、四窗格；每个窗格拥有独立的 2D/3D 内容、相机、选择和编辑状态。工具栏、代数区域和 Agent 操作始终作用于焦点窗格。

## 已确认的产品规则

- 启动时显示单窗格。
- 三窗格布局固定为左侧一个大窗格、右侧上下两个小窗格；四窗格为 2×2；双窗格采用左右布局。
- 增加窗格时，新窗格为空白；减少窗格时只隐藏多余窗格，不清除内容。
- 窗格只要没有被用户删除，内容就在当前运行期间保留；删除后自动选择合法布局并更新焦点。
- 第一版不把普通窗格状态写入数据库或场景持久化；场景快照协议增加 `panes` 字段，同时保留旧单场景字段用于兼容读取。
- 默认名称为“窗格 1”至“窗格 4”，名称可编辑。
- 焦点由点击、键盘进入和工具操作前同步；不增加额外的“当前窗格”选择器。
- 代数区域显示一个 Tab 容器；Tab 与窗格双向同步，切换窗格自动激活对应 Tab。切换前自动提交未完成的公式编辑。
- 2D 与 3D 模式在每个窗格内独立保存；现有场景模式按钮切换时，显示该窗格上次保留的对应模式状态。
- 第一版 2D 支持点、线、函数和标注；支持矩形多选、多对象复制/粘贴。跨窗格粘贴保持原坐标；在同一窗格复制时自动平移一个网格单位避免重叠。
- 所有窗格共享一个全局撤销/重做历史，撤销按操作发生顺序执行，不要求操作发生在当前焦点窗格。
- Agent 请求开始时锁定焦点窗格 A；执行期间即使焦点改变，操作仍写入 A。Agent 回合恢复使用完整多窗格快照。
- 线性代数教学案例使用独立的案例 Tab/视图，不占用、不替换普通工作区窗格；普通窗格已有 1–4 个时，打开向量加法不会再创建冲突窗格。
- 最多四个 `QtInteractor`。恢复时优先刷新；渲染器失效时按窗格状态重建，并自动重试，不显示额外重试按钮。
- 不保留旧的 `self.plotter` 兼容代理，直接迁移调用链到 Pane Manager。

## 架构

### ScenePaneState

每个窗格由稳定的 `pane_id` 标识，保存：

- 可编辑显示名；
- 独立的 2D 场景模型、3D 场景模型及当前模式；
- 2D/3D 相机状态；
- 选中对象集合；
- 视口 renderer/interactor 引用（可按需创建和销毁）；
- 当前窗格的代数 Tab 模型。

状态对象不依赖 Qt 控件，便于快照、复制粘贴和单元测试。

### ScenePaneManager

Manager 负责：

1. 创建和删除窗格，保证最多四个稳定 ID；
2. 管理当前可见窗格集合和四种布局；
3. 记录 `active_pane_id`，处理焦点事件；
4. 将工具、代数编辑、选择、复制粘贴和 Agent 操作路由到目标窗格；
5. 在最小化恢复、窗口 resize 和 renderer 失效时刷新或重建视口；
6. 维护跨窗格的全局操作历史。

布局按钮只改变可见性和几何位置，不改变窗格内容。若当前焦点窗格被隐藏，Manager 选择布局中第一个可见窗格并同步代数 Tab。

### 主窗口集成

主窗口不再持有单例 `plotter`、`geometry_controller`、`curve_controller` 等场景状态。所有场景入口显式接收目标 pane 或通过 Manager 获取焦点 pane。右上角使用四个带中文 accessible name 的图标按钮，提供选中态、工具提示和主题重染。

### 代数区域

代数面板使用 `QTabWidget`（或等价容器）管理 pane tabs。Tab 内容模型按 pane ID 存储；Tab 标题编辑只修改显示名，不改变 pane ID。隐藏窗格的 Tab 不参与可见布局，但模型继续保留。教学案例 Tab 位于独立案例容器，不加入普通 pane tabs。

### 复制/粘贴边界

剪贴板使用带版本号的 JSON-safe 快照，仅允许点、线、函数、标注及其必要样式/坐标字段；不包含 Qt/PyVista 对象、renderer 或可执行内容。粘贴时重新生成对象 ID，并作为一次原子操作写入全局历史。跨窗格粘贴不改变坐标；同窗格重复粘贴在 x/y 方向各偏移一个网格单位。

### Agent 与快照

Agent 场景上下文携带 `active_pane_id` 和 `panes`。`panes` 包含每个窗格的模式、名称、场景对象、相机和代数数据；旧字段继续输出以兼容旧消费者。请求启动时记录目标 pane ID，后续事件不得因焦点变化而改写目标。教学案例事件继续走独立协议通道。

## 错误处理与恢复

- 创建第 5 个窗格时拒绝操作并保持当前布局。
- 删除最后一个窗格时拒绝删除，确保至少保留一个窗格。
- 粘贴快照校验失败时不修改场景、不写入历史，并记录可诊断日志。
- renderer 初始化或恢复失败时按退避策略自动重试；失败期间显示窗格占位状态，不影响其他窗格。
- 最小化/恢复流程必须重新计算可见窗格尺寸并触发 render；失效 renderer 由 Manager 重建。

## 测试策略

- `ScenePaneState`：状态隔离、稳定 ID、模式和相机独立性。
- `ScenePaneManager`：四种布局、隐藏/恢复、删除后布局修正、焦点同步和全局历史顺序。
- Qt 集成：图标按钮可访问名称、Tab 双向同步、公式编辑自动提交、工具只作用于焦点窗格、最小化恢复不白屏。
- 复制粘贴：JSON 校验、对象 ID 重生成、跨窗格坐标保持、同窗格网格偏移、原子撤销。
- Agent/协议：`panes` 快照兼容、请求锁定窗格、教学案例与普通窗格隔离。
- 回归：现有 2D/3D、线性代数案例、Web 前端构建及完整 Python 测试。

## 范围外

- 跨窗格实时联动绘制、同步相机和协作编辑。
- 第一版 3D 的完整工具迁移；3D 先保证独立显示、独立相机和模式状态。
- 跨应用或跨启动周期的普通窗格持久化。
