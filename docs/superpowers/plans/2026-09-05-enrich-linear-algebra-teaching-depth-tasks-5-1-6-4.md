# Linear Algebra Teaching Content and Runtime Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate and review all 54 lecture-grounded teaching artifacts, compile the focus-topic visuals, and expose one validated topic bundle to Qt and Web readers.

**Architecture:** Published JSON resources live below `linear_algebra/teaching/data` and are loaded through `TeachingArtifactStore`. Each chapter is generated by the dedicated explanation-agent contract and reviewed before its index changes. `CurriculumRegistry` resolves a `TeachingBundle` containing one topic, artifact, contract, and compiled snapshot; UI code receives a prepared JSON-safe case projection only after bundle validation.

**Tech Stack:** Python 3.11+, existing catalog/registry and scene command service, PySide6, React 18/TypeScript/Vitest, pytest, versioned UTF-8 JSON resources.

**Spec:** `openspec/changes/enrich-linear-algebra-teaching-depth/design.md` and all six capability specs under `openspec/changes/enrich-linear-algebra-teaching-depth/specs/`.

## Global Constraints

- All 54 artifacts must derive from `.agents/线性代数讲义.md`; no exercise, self-check, challenge, or chapter-4 content is included.
- The accepted sub-agent JSON is retained for audit; runtime receives normalized published artifacts only.
- Every chapter is 24/15/15 topics and every artifact passes source, depth, numeric, claim, and visual-contract validation before publication.
- A tree selection uses one stable `topic_id`; title/formula similarity never selects a visual.
- Scene and explanation remain unchanged when bundle resolution, plan validation, execution, or case projection preparation fails.
- Web payloads are bounded and JSON-only; no scene operations, raw replies, renderer objects, or credentials cross the bridge.

## File Structure

- Create `linear_algebra/teaching/data/index.json`: published topic/revision index.
- Create `linear_algebra/teaching/data/published/ch01|ch02|ch03/*.json`: normalized artifacts.
- Create `linear_algebra/teaching/data/audit/ch01|ch02|ch03/*.json`: accepted raw-response audit records.
- Create `linear_algebra/teaching/content_validation.py`: chapter resource coverage checks.
- Create `linear_algebra/bundle.py`: immutable runtime bundle and resolver.
- Modify registry, loading, Qt content, Web bridge/types/reducer/reader, and their focused tests.

```python
@dataclass(frozen=True)
class TeachingBundle:
    topic: LessonEntry
    artifact: TeachingArtifact
    artifact_digest: str
    contract: VisualContract
    recipe: VisualizationRecipe
    compiled: CompiledResource
    stale: bool


def get_bundle(self, topic_id: str) -> TeachingBundle:
    topic = self.get_topic(topic_id)
    loaded = self.artifact_store.load_published(topic_id, current_context=self.source_repository.context_for(topic))
    contract = contract_for(topic_id)
    compiled = self.compiled_store.resolve_or_compile(loaded.artifact, contract)

    return TeachingBundle(topic, loaded.artifact, artifact_digest(loaded.artifact), contract, self.get_recipe(topic.visualization_id), compiled, loaded.stale)
```

```python
@dataclass(frozen=True)
class PreparedTopicSelection:
    bundle: TeachingBundle
    plan: CommandPlan
    case_payload: dict[str, object]


def prepare_topic_selection(registry, topic_id: str) -> PreparedTopicSelection:
    bundle = registry.get_bundle(topic_id)
    case_payload = project_case(bundle)
    plan = CommandPlan(
        scene=bundle.compiled.plan.scene,
        summary=bundle.compiled.plan.summary,
        operations=({"op": "scene.clear", "scope": "all"}, *bundle.compiled.plan.operations),
    )
    validation = SceneCommandService().validate(plan)
    if not validation.valid:
        raise TopicLoadError(topic_id, "plan_validation", validation.messages)
    return PreparedTopicSelection(bundle, plan, case_payload)
```

```python
class ExplanationSection(QWidget):
    def set_section(self, title: str, body: str | tuple[str, ...]) -> None:
        lines = (body,) if isinstance(body, str) else body
        visible = any(line.strip() for line in lines)
        self.setVisible(visible)
        self.title_label.setText(title)
        self.body_label.setText("\n".join(lines))


def set_artifact(self, artifact: TeachingArtifact) -> None:
    content = artifact.explanation
    self._set_sections(_section_projection(content, artifact.claims))
    self.setProperty("artifactRevision", artifact.revision)
    self.setVisible(True)
```
